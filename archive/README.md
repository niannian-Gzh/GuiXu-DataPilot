# 存档

这里放**要留着、但不参与运行**的东西。工程目录（`src/` · `data/` · `logs/`）
只留应用本身和它的运行数据，根目录只回答「怎么把它跑起来」。

| 目录 | 是什么 |
|---|---|
| `docs/` | 设计稿（design）、界面语言（design-language）、进度存档（progress）、决策素材（decisions）、旧题库（eval-questions） |
| `drafts/` | 数据层重写时的三份草稿：快照 / 软删除 / 表定义 |
| `proto/` | 界面原型：工作台、品牌第五版 |
| `brand/` | 图标源文件（svg / png / ico）。README 顶部那张图从这里取 |
| `eval/` | 旧的冒烟评测。期望值对着旧数据硬算，正在重写——题目与覆盖面见 `docs/eval-questions.md` |
| `legacy/` | 旧数据层的 DuckDB、示例表、旧文件审计、已迁进库的 `schema_meta.json`。**只在本地，不进版本库** |

## 为什么这么放

- **运行与记录分开**：看代码的人先看到应用怎么跑；要追溯某个决定为什么这么做，再来这里。
- **死文件单独一处**：原型、草稿、废弃数据混在 `docs/` 和 `data/` 里时，谁也说不清哪个还在用。
- `legacy/` 是唯一被 `.gitignore` 挡住的目录——旧数据有一两兆，不值得进库，但删了又可惜。
