# 归墟 设计语言

> **源**：`css/splash.css` + `js/boot.js`（开机动画，来自 dsh-startup-screen，MIT）。
> 它是本项目的视觉起点，**但只是起点**。
>
> **实物**：`docs/proto/workbench.html`（可交互原型，按 `1/2/3` 切屏、`L` 切线的有无、`P` 切产物栏）
>
> 这份文档是**从实物反推**的，不是从意象演绎的。写完于 2026-10-15，
> 在此之前它被推翻重写过一次，被推翻的条目集中记在最后一节。

## 零 · 第一判据

**开机动画是仪式，工作界面是日用品。**

仪式可以像仪器——三秒钟，冷、硬、密、不说话，那是它的本分。
日用品不行。日用品是拿在手上、每天要用的东西，**它不该时刻提醒你"我是一台设备"**。

> **这一条排在所有规则前面，而且它有权推翻它们。**
> 下面每一条如果和它冲突，改的是下面那条。

**判据**：一个新用户第一次打开，**需不需要先弄懂什么才知道怎么用？**
需要，那就有地方还在说仪器的话。

## 一 · 色

### 1.1 灰阶是暖的

```
--ink       #f2f1ee   242 241 238   正文
--ink-soft  #cfcecb   207 206 203   次级文字
--muted     #85847f   133 132 127   弱文字、标签
--faint     #6a6965   106 105 101   最弱
```

**规则：文字一律 `R ≥ G ≥ B`。**

**底也一样**——五档底色全部 `R ≥ G ≥ B`，整条灰阶轴没有一处偏冷。暖白在深底上更接近纸和墨，读起来不刺。

**这里走过一次弯路，记下来。** 想让工作区"更深邃"，第一次理解成"往冷走"，把工作区三档调成了蓝黑（`B − R` 到 +10）。结果是整块泛蓝，和四周的暖灰割裂——那不叫深邃，叫换了个色相。

**深邃要的是同一个色相里压得更黑，不是换色相。** 现在工作区那三档比早先暗了 20%（`--bg` 的感知亮度 14.9 → 11.9），色温一动没动。

### 1.2 底色四档明度 —— 深色 ≠ 近黑

```
--void    #050504   页面底色（满窗口后只在启动和边角露出）
--side    #1a1917   框：顶栏 + 左右栏
--bg      #0c0c0b   工作区（凹面）
--raise   #161513   工作区里的块：结果框、气泡、产物栏
--sunken  #070706   输入框
```

**这是全文件最重要的一条。**

近黑区间（RGB 0~20）**没有分层的空间**——分三层每层只能分到 7 个色阶，肉眼分不出来。
早期版本全站挤在 `#0b0b0c` 附近，所以怎么调都是"平"的。

**规则：相邻两档至少拉开 8 个色阶。**

### 1.3 明暗分层与「线」是替代关系

```
框（亮） → 工作区（暗） → 块（更亮）
```

**两者不是叠加，是替代。** 分层做实了，线就要减；两样一起上，屏幕会被切成几十个格子，读起来是"压迫"。

**一个例外：工作区要多一圈 1px 的边。**

`1.2` 的 8 个色阶是**下限**——刚够在两块小面积之间分开。工作区是另一种情形：面积占了大半屏，而且右、下、左三面被同一个颜色（`--side`）包着。这种位置上，11 个色阶也看得见，但大脑会把它读成「同一块面上的两个区域」，不是两个面。

所以 `.stage` 是 `--bg` 的底色 **加上**一圈 `--hair-soft` 的边和一记短投影。判据不是「分层够不够」，是**这块面要不要被认成独立的一个面**。它的顶端直接接页头，不再额外留一条空带。

它不会变成"压迫"：压迫来自线**到处都在**（几十个格子），而不是来自某一条线。全屏只有这一圈。

**线的值**（暖白，不是纯白——纯白在暖底上发冷）：

```
--hair-soft    rgba(255,250,244,.10)   极弱分隔
--hair         rgba(255,250,244,.20)   常规
--hair-strong  rgba(255,250,244,.36)   元素边界
```

**规则：线一律 `rgba(255,250,244,α)`，不用灰色，不用纯白。**

### 1.4 色相只给信号、文件和品牌

```
--acc        #3d7dff   强调 / 当前 / 进行中
--ok         #3ddc97   成功
--err        #f87272   失败
--warn       #d99b3c   警告 / 待确认
             #4fd18b   .xlsx
             #6aa9ff   .csv
```

**语义色的浅底与半透明边必须派生，不许手写 RGB：**

```css
--err-dim:  color-mix(in srgb, var(--err) 12%, transparent);
--err-line: color-mix(in srgb, var(--err) 34%, transparent);
```

### 1.5 永不改变的东西是装饰，不是状态

**一个永远不变的东西，不承载信息。**

- 本地应用连不上模型就进不了工作台 → "已就绪"那个点**永远亮着** → 它不跟状态色走，跟 `--acc`
- 反过来，如果某个数字长期不动，它就是在占位置

**判据**：把这块拿掉，用户会不会少知道一件事？不会，它就是装饰。

## 二 · 光

### 2.1 近黑底上不许用大面积低透明度渐变

**这条是踩出来的。**

`--bg` 是 RGB 15，叠一层 `.05` 的白，从 0 到最亮**只有 12 个色阶**，摊在几百像素上**必然跳阶**。看起来像一条"分层的边"，其实是渐变跳了一阶。

**规则：层次用【实色】做，不用渐变。** 想加的那层"环境光"，在近黑底上做不到。

### 2.2 三个禁令

| 不许 | 因为 |
|---|---|
| 在中心打光 | 中心是主体所在，打光等于打聚光灯——读起来是"刻意" |
| 凹面发光 | 逻辑矛盾：一块凹进去的地方不该亮 |
| 用模糊半径造"亮" | 要亮就提色值。零模糊硬阴影可以，模糊投影不行 |

### 2.3 亮 ≠ 发光

| ❌ | ✅ |
|---|---|
| `drop-shadow(0 0 Npx 色)` | 提色值明度 |
| 柔光晕 | `box-shadow: 0 0 0 1px 色`（零模糊） |

**允许的模糊只用在结构浮层上**：工作区的短投影、弹窗/下拉/提示条的投影。它们表达"这是一块离开底面的东西"，是结构不是光；不用来造辉光。

## 三 · 形

### 3.1 圆角

```
页头       0（满宽，不切圆角）
工作区     12px
产物栏     12px 0 0 12px   （右侧被工作区裁着，只加左边）
弹窗       14px
块         8~10px
按钮       6~8px
输入框     10px
图标方块   9px
标签       3px
圆点/光环  50%
```

> **圆角 0 是旧规则，已推翻。** 直角来自开机动画（它一处圆角都没有），但那是 3 秒的仪式；日用品需要圆角。

### 3.2 线只有两档

```
1px     分隔 / 边界 / 刻度
1.5px   按钮的一圈、输入框
```

**按钮的边界要比分隔线重，这是故意的。** 不允许 2px、0.5px。

### 3.3 尺寸一律 `min()` 双约束

```css
width: min(560px, 42vw)
```

任何会随窗口变化的尺寸，同时给绝对值上限和视口比例。只给一个，要么大屏失控，要么小屏挤扁。

### 3.4 出现动画做在尺寸上

```css
width: 0 → min(340px, 42vw)
```

**不是淡入，是"长出来"。** 这是开机动画最主要的出现方式，工作界面沿用。

### 3.5 刻度的正确用法

**刻度线是「附在某条线上的刻度」，不是背景纹理。**

它在开机动画里只出现一次——底部进度条上方那 5px 高的尺。把它拉满全屏等于把尺子当墙纸用。

**正确**：附在一条线上做标记（列表项行首的短横、进度条的刻度）
**错误**：铺满背景

## 四 · 字

### 4.1 等宽只给「要竖着对齐比对」的东西

```
✅ 表格里的数字列       ✅ 工具名、函数名
✅ 耗时、行数、时间戳    ✅ SQL、路径、标识符
```

**❌ 不是"来自系统的就用等宽"。**

> 旧规则写的是「来自系统的 → 英文等宽；来自人的语言 → 中文」。
> 这条太宽了，实际执行下来满屏都是等宽（曾达 24 处），全屏在"广播"。
>
> **新判据：这个东西要不要和它上下的东西对齐着比？**
> 要 → 等宽。不要 → 无衬线。

**曾经被误判成等宽的**：品牌名、状态标签、计数（`2 表 · 1,204 行`）、文件名、导航、按钮、会话项 meta。

### 4.2 不用大写

**`text-transform: uppercase` 全站删除。** 中文界面没有它存在的理由，英文标签也不靠全大写取得分量。

### 4.3 字距克制

```
正文          0.015em
标签          0.04 ~ 0.10em
品牌名        0.16em
```

**不要 `.2em` 以上**（品牌名除外）。开机动画里那些 `.34em`、`.58em` 是"铭牌感"的来源，但铭牌是给人扫一眼的，不是给人读一天的。

### 4.4 字号下限

```
开机动画    9.5px
引导页      10px
工作界面    10.5px   ← 绝对下限。只给「贴在别的东西上的极小标签」：
                       徽章、角标、行内微型按钮
            11px     ← 常规小字的下限。刻字、meta、hint 都从这里起
```

**为什么徽章能到 10.5 而别的不能**：它总是贴着一个比它大的字（11.5px 的工具名、12.5px 的设置项），同号会和那个字打架；小半号，它才退成「附着物」，而不是「另一个字段」。

**这一条属于"音量分级"，见第六章。**

### 4.5 字号跨度要大

```
10.5 · 11 · 11.5 · 12 · 12.5 · 13 · 13.5 · 14 · 14.5 · 16 · 18 · 22 · 27
```

**一个界面里应该同时有 10.5px 和 20px+。** 全是中间号 = 没有层次。

**这张表是封闭的**：`app.css` 里出现的每一个字号都必须在这个列表里。多出来的那个通常不是「需要一个新档」，而是「随手写了一个数」。查法见第七章。

### 4.6 品牌锁排

```css
.tb-brand{ padding:0 16px; gap:10px; }
.tb-mark{ width:28px; height:28px; }
.tb-name{ font-size:18px; font-weight:700; letter-spacing:.16em; color:var(--ink); }
.tb-divider{ width:1px; height:16px; background:var(--hair); }
.tb-sub{ font-size:11px; letter-spacing:.1em; color:var(--muted); }
```

**名字和副标题之间要有结构，不能只靠字号差。** 早先把「归墟」和「数据处理 Agent」直接并排，副标题像一句掉在旁边的尾巴；竖线给副标题一个明确的从属位置。标记 28px，名字 18px，副标题 11px，三档拉开。

**品牌字不再做倾斜和渐变。** `skewX(-10deg)` + 蓝白渐变 + 极小的副标题叠在一起，字会显得吵；名字用实色暖白，副标题退到 `--muted`。页头只保留一条品牌锁排，左栏不再重复第二块品牌。

### 4.7 文案

**产品文案必须通用，用户数据可以具体。**

| | 例子 | 该不该具体 |
|---|---|---|
| 用户的数据 | 软著登记号、`projects`、`打回明细.csv` | **越具体越真实** |
| 产品文案 | 空态的可问示例 | **必须通用** —— 它对每个用户都一样 |

> 写过一版"把已下证的项目导成 Excel"当空态示例——那是**拿一个特定数据集的内容写了产品文案**，等于只服务第一个用户。

**说人话**：`第 3 轮` 不是 `ROUND 03`，`用时 2 分 14 秒` 不是 `ELAPSED 2M 14S`。

## 五 · 组件

### 5.1 对话

**用户的话是气泡，Agent 的话是日志流。**

```css
/* 用户：右对齐 + 贴合内容宽度的气泡 */
.turn.op .turn-text{
  width:fit-content; margin-left:auto; max-width:74%;
  background:var(--raise); border-radius:14px 5px 14px 14px;
}
```

**Agent 那侧不加气泡**——它的内容是长文 + 工具 + 表格，装不进泡泡里。

**气泡宽度要贴合内容。** 拉满 74% 但只装一行字，中间会空一大片——**气泡的宽度本身就是信息，短句就该是短的**。

**两侧正文同色（`--ink`）。** 曾经把 Agent 的话调暗一档，那等于在说"Agent 说的不太重要"；谁说的靠标签和位置分就够了。

**Agent 有头像**：28px 的归墟标记，用 `--ink-soft`。头像是"谁在说话"最直接的标记，比读标签快。

### 5.2 工具调用

等宽 + 状态标签，等宽是有意的——**它和对话正文形成对比，一眼分得清"在干活"和"在说话"**。

### 5.3 面板

**不用卡片。** 三栏是**一整块工作台**，靠明暗分区，不靠三个圆角盒子浮在背景上。

有一层 52px 全宽页头：左边品牌锁排，右边窗口按钮，中间是拖动区。品牌不再单独占左栏顶部——两个页头会出现台阶，品牌想跨过去又会变成 L 形。

工作区是一块**凹进去的圆角面**，靠一圈 1px 暖白边和短投影站住；右、下留 20px，左留 8px，顶端直接接页头。

### 5.4 可收起的分栏

**开关放在常驻位置**（顶栏），不能放在分栏自己身上——**栏收起来之后，那个按钮就跟着一起没了**。

---

### 5.5 空态是「待机」，不是「新会话」

**空态不放头**：不放标题、不放分隔线、不放视图切换、不放产物栏。

因为**「待机」和「执行」是两种气质**：

- **执行时**给日志、给时间戳、给 `OK 38ms`——用户需要一个"它在动"的证据
- **待机时什么都不给**——终端待机是黑屏加闪烁光标，那是"等待输入"的紧张感，**盯着它的人是紧张的**

屏保该是安静的：**标记、一句话、三个例子，别的都不要。**

### 5.6 视图切换属于工作区，预览用弹窗

**「对话 / 轨迹」放在工作区顶栏**，不在左栏——它是**这一个会话**的两个视图，不是整个应用的视图。左栏那个位置该是"会话列表"自己的事。

**点产物用弹窗**，不是换视图。会话留在底下，遮罩**只盖工作区**（左栏右栏还能点）。

早先做成"接替工作区"（整块换掉、左上角返回）是错的——**那等于看个文件就丢了对话现场**。

### 5.7 设置的「高级」是个信号

**当一堆设置项只能塞进「高级」时，通常意味着它们不该出现在界面上。**

判据：**用户会不会为了这件事打开设置页？**

| | 处置 |
|---|---|
| 会 | 放出来，用日常语言写标签 |
| 不会 | 移出界面，留在配置文件里，文档说一句 |

尤其注意**安全阀**（熔断上限、重试次数）——**它们更不该让用户关掉**。

**数值型设置把范围写在框里**（`256 – 8192`），不写在说明里——**它是这个框的约束，属于框本身**。

**只读的值不该长得像能填的框**：无边框、右对齐、颜色更弱。

### 5.8 数字的口径要写下来

`2 表 · 3,929 行` 这类概览数字，口径是**「已入库」**，不是**「正在处理」**。

所以文件拖进来了、但用户还没点确认建表时，它仍然该显示 `0 表`。

### 5.9 长文本折行，不截断

**用户用来相认的文本**（产物名、会话标题），宁可折成两行，不要省略号。

文件名常常很长（「2026年第三季度华东区销售明细汇总」），截断成「2026年第三季度华东区…」**等于什么都没说**——用户认的往往就是后半截。

## 六 · 音量分级

|  | 开机动画 | 引导页 | **工作台** |
|---|---|---|---|
| **气质** | 冷硬工业 100% | 稍收 | **日用品：六成工业 + 四成人味** |
| 字号下限 | 9.5px | 10px | **10.5px**（只给徽章角标），常规小字 11px |
| 字号上限 | 44px | 27px | **27px**（只给空态标题），正文区 20px |
| 元素密度 | 满 | 减 | 更减 |
| 音效 | ✅ | ✅ | **❌ 全程静音** |
| 暗角 | ✅ | ✅ | ❌ |
| 柔光 | ✅ | ✅ | ❌（近黑底上做不到，见 2.1） |
| 等宽 | 多 | 中 | **收窄到只给对齐用的** |
| 圆角 | 0 | 有 | 有 |

**开机动画本身一个像素都不动。** 它三秒的仪式，冷硬是正确的。

## 七 · 强制力

**能 grep 得到答案的才算规则。**

| 检查 | 命令 | 期望 |
|---|---|---|
| 有没有大写 | `grep -n "text-transform:uppercase" css/*.css` | 0 |
| 有没有 `.2em` 以上的字距 | `grep -n "letter-spacing:\.\?[2-9]" css/*.css` | 0（品牌名是 .14em，够不着这条线） |
| 字号有没有跑出档位表 | `grep -oh "font-size: *[0-9.]*px" css/app.css \| sort -u` | 见 4.5，正好 12 个值，一个不多 |
| 有没有写死的带色相 rgba | `grep -n "rgba([0-9]" css/app.css` | 只有无彩的（R=G=B，或暖白 / 黑） |
| 有没有大面积渐变 | `grep -n "radial-gradient" css/app.css` | 0 |
| 相邻明度差 | 抽查 `void → side → bg → raise` 这四档 | 相邻 ≥ 8（按感知亮度 `0.2126R+0.7152G+0.0722B` 算，不是 RGB 平均值） |
| 输入框看得出是个框 | 看 `.field` | 靠它那圈 1.5px 的边，不靠底色差——`--sunken` 和工作区只差 4，本来就够不着 8 |
| 文字和底是不是都暖 | 抽查 `--ink` 系和五档底色 | `R ≥ G ≥ B` |

**第三条原来写的是「有没有小于 11px 的字」，那条 grep 本身就漏了空格**（`font-size: 10.5px` 带空格，匹配不到），于是报出来的 0 是假 0——实际有五处 10.5px。改成上面这条：它不预设下限，而是把用到的字号全列出来对表，跑出一个表外的值一样能看见。

**范围就是命令里那个路径。** `css/app.css` 只量工作台，`css/*.css` 两张表一起量。
开机动画（`css/splash.css`）属于另一档音量——暗角、径向渐变、成片的信号色都在它那儿，
不拿工作台的尺子去量它（见第六章）。

**最重要的一条**：grep 不到答案的规则，**要么改写成能 grep 的，要么删掉**。

## 附一 · 这一路推翻过什么

**写在这里是为了别再踩一遍。**

| 曾经的规则 | 为什么错 | 现在 |
|---|---|---|
| 结构件圆角一律 0 | 直角来自开机动画（它确实一处圆角没有），但那是 3 秒的仪式 | 见 3.1，圆角回来了 |

## 附二 · 从哪来，到哪去

| | |
|---|---|
| 视觉源头 | `css/splash.css` + `js/boot.js`（开机动画） |
| 实体验证 | `docs/proto/workbench.html` |
| 上游 | dsh-startup-screen（MIT）— DeepSeek Harness 的启动屏 |

**落地方式**：`docs/proto/workbench.html` 的整份 CSS 搬进了 `src/web/static/css/app.css`——
不是"照它重写一遍"，是**逐字搬**。原型那份是从令牌到组件一次写成的、自洽的一套，
在旧样式上按块打补丁只会得到"看着像、哪儿都不对"的东西（这个坑走过一次，见附一）。

配套：模板的类名一律对齐原型（`.turn.op` / `.step-nm` / `.set-row`…），
六个旧样式表（base / layout / chat / files / settings / schema）已删。
现在 `css/` 下只有两张表，各管各的 DOM，没有一条规则需要覆盖另一条：

```
splash.css   开机动画（选择器一律挂在 #dsh-startup-root 下面）
app.css      工作台（原型搬来的 + 原型没演到的状态）
```
